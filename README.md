# DSH 本地待办看板 · dsh-local-board

DeepSeek Harness 的左侧导航任务看板：**Todo / Doing / Done 三列**，按项目组织。

**数据是你自己的**：第一次打开会让你选一个文件夹，看板在里头生成一个 `看板.md`，所有任务都在这个文件里。放哪都行——Obsidian 仓库、iCloud、坚果云、U 盘，随便；换机器把这个文件夹拷走就是完整迁移。

## 特性

- 左侧导航栏常驻入口，点开是整页看板
- 三列看板，卡片**拖拽**流转；也能直接拖到左侧项目名上换项目
- 每个项目有状态（进行中/暂停/已结束，左侧圆点用颜色区分）、角色（我负责/需跟进/仅知晓）
- 卡片支持：负责人、优先级、截止日期**精确到分钟**、备注、**颜色标记**、**私密打码**（默认遮罩，点一下才显示）
- 逾期标红、今天到期标橙
- 顶部「打开文件夹」一键在访达中定位数据目录
- 搜索、按截止日排序、新建项目、重命名、删除（删除会归档到文件末尾，可恢复）
- 面向 Agent 的 `kanban` 工具，可以在对话里直接读写看板

## 数据在哪

第一次打开面板时会让你**选一个文件夹**，选择记在 `~/.dsh/kanban/settings.json`，之后一直用这个目录。

也可以跳过选择界面，直接在 profile 的 `cordis.patch.yml` 里固定：

```yaml
- id: kanban
  config:
    vaultDir: '/你的/路径/看板'
```

文件长这样，用任何编辑器都能直接读改：

```markdown
## 童话镇守卫战

- 角色: 我负责
- 状态: 进行中

### Todo
- [ ] 修好泡泡糖发射器 · @小呆呆 · #P1 · 📅2026-11-12 14:30 ^k-a1

### Doing
- [ ] 特训菲菲的魔法棒 · 🎨blue · @菲菲 · 📝周三下午在糖果广场集合 ^k-a2

### Done
- [x] 把怪兽赶出糖果森林 · ✅2026-11-05 ^k-a3
```

这是纯 Markdown，用任何编辑器都能打开和手改。

- `🎨` 后面是颜色名（red/orange/yellow/green/blue/purple/gray）
- `🙈` 表示该卡片在界面上默认打码
- `^k-xxxxx` 是稳定 ID，请勿删除
- `[ ]` 改成 `[x]` 即完成

## 定时提醒（仅 macOS）

装好后会自动创建三个 LaunchAgent，可在面板「自动化」标签里改时间、停用：

| 任务 | 默认 | 内容 |
| --- | --- | --- |
| 每日摘要 | 每天 09:00 | 今天到期的卡片（按时间排序）+ 已逾期 |
| 临近提醒 | 每 30 分钟 | 仅在 2 小时内有卡片到期时提醒，同一条不重复 |
| 周回顾 | 每周一 09:30 | 上周完成、进行中、待办、逾期 |

> macOS 的隐私保护会拦住定时任务读取 `~/Documents` 这类受保护目录；插件每次保存时都会往 `~/.dsh/kanban/board-snapshot.md` 写一份快照，任务读不到原文件时自动用快照。

### 已知边界

一台机器同一时间**只支持一个数据目录的定时提醒**——三个任务在系统里各只有一份，指向最后一次配置的目录：

- 换目录：在面板里重新选即可，任务会自动跟着走（旧目录不再提醒，数据不受影响）
- 同时用两个 profile、各配不同目录：只有最后配置的那个会收到提醒
- 不需要提醒：在「自动化」里逐个停用即可，看板功能完全不受影响

## 平台

看板本体跨平台；定时提醒依赖 `launchctl`，仅 macOS 生效，其他平台「自动化」标签隐藏。
